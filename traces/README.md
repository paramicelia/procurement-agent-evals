# traces/

`ci_gate.jsonl` is a **fixed, committed example** trace (42 spans from a real
recorded-cassette gate run) — the file the README's trace-viewer link points
to. It is not regenerated by `scripts/run_gate_locally.sh`, so it won't
change every time you run the gate.

Running the gate or the eval harness locally writes fresh, gitignored trace
files instead (`ci_gate_run.jsonl`, `eval_run.jsonl`, `run.jsonl`). Regenerate
the committed example deliberately with:

```bash
python trace_viewer/render_trace.py traces/ci_gate.jsonl trace_viewer/report.html
```
